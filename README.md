# Alt-F4-Fishes
A small and chill pixelated aquarium idle/management game for my Neocities page and anyone that comes across it.
Trying to learn as I code, using W3Schools and Anthropic Claude AI as a teacher and support.

Built with: plain HTML, CSS and JavaScript, no frameworks

Current status: Working on v0
